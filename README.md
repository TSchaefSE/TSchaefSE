## Featured Project

### Concrete Batch Analysis & Strength Prediction (CBAS)
**Client: Vulcan Materials Company**

*Backend Lead / CTO — Software Engineering Capstone Project*

CBAS is a desktop application developed to help analyze concrete batch data, monitor curing conditions, and estimate compressive strength before traditional 28-day break testing.

The application combines a mathematical prediction engine, historical testing data, and curing sensor measurements to provide engineers with actionable insights into concrete strength development.

**My Contributions**
- Led backend architecture and development, coordinating technical decisions and implementation across the team.
- Designed and implemented REST API endpoints using ASP.NET Core.
- Developed and integrated a deterministic strength prediction engine using concrete maturity calculations and engineering models.
- Implemented prediction recalibration using measured 3-day and 7-day compressive strength results.
- Integrated SQLite and Entity Framework Core for local data persistence.
- Developed validation, early-warning, and strength-risk assessment functionality.
- Contributed to Angular frontend integration and report generation.
- Implemented automated testing and supported CI workflows using GitHub Actions.
- Documented architectural decisions, calculation methodologies, and engineering requirements.

**Technology Stack**

`C#` `ASP.NET Core` `.NET` `Angular` `TypeScript` `SQLite` `Entity Framework Core` `WPF` `WebView2` `xUnit` `GitHub Actions`

**Key Engineering Concepts**

RESTful API Design • Software Architecture • Mathematical Modeling • Data Persistence • Predictive Calculations • Automated Testing • Technical Leadership
